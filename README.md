# Five Keys

A static website for Five Keys.

## Project structure

```
index.html      Main HTML entry point
css/style.css   Site styles
js/main.js      Site scripts
```

## Development

This is a plain static site — no build step required. Open `index.html`
directly in a browser, or serve the folder with any static file server.

## Deployment

The site is intended to be hosted on [Cloudflare Pages](https://pages.cloudflare.com/).
It's kept dependency-free and free of server-side assumptions so it can be
deployed as-is once Cloudflare Pages is configured.
